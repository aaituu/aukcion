# AURUM Signal — демонстрационный аукцион

Статический интерактивный прототип по техническому заданию цифрового гибридного аукциона. Работает без сервера, базы данных и регистрации.

## Что работает в демо

- навигация между главной, каталогом, карточкой лота и Live-залом;
- поиск и фильтрация лотов;
- избранное;
- серверный таймер 50 секунд в демонстрационном режиме;
- обязательное подтверждение перед каждой ставкой +3%;
- запрет перебивать собственную последнюю ставку;
- имитация ставки конкурента с Blind ID;
- история ставок;
- демонстрация SLA Freeze;
- экран Runner-Up;
- кабинеты инвестора, продавца и партнёра;
- форма регистрации партнёрского лида;
- экран победителя и контакт продавца;
- адаптивная версия для телефона.

## Как открыть локально

Откройте `index.html` двойным нажатием. Интернет и установка пакетов не нужны.

## Как опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этой папки, сохранив папку `assets`.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/root` и нажмите `Save`.
6. Через несколько минут GitHub покажет публичную ссылку.

## Важно

Это визуальный прототип для презентации клиенту. Digital ID, банковский Hold, PostgreSQL, Redis, WebSocket, государственные реестры, SMS/Push и настоящие платежи здесь только показаны интерфейсом и не подключены. Для реальной эксплуатации потребуется backend и отдельный аудит безопасности.
